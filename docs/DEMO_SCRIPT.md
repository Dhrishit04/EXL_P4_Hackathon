# Three-minute demo script

Use the deployed app with real generated artifacts. Do not present fixture
values as results. If a real artifact is unavailable, state that clearly
instead of substituting a fixture number.

| Time | Clicks | Say |
| --- | --- | --- |
| 0:00–0:15 | Open **Home**. Point to the pipeline board. | “ModelProof helps a bank validate a large legacy model estate with evidence, deterministic checks, and human decisions at every gate.” |
| 0:15–0:45 | Open **Inventory**; locate the target under **Model records**, expand its record, and point out the seeded security finding. | “The inventory makes ownership and model risk visible; this flagged item is seeded for the demonstration and is not a production incident.” |
| 0:45–1:15 | Open **Model detail**, select the target in the model selector, then open **Documentation**; expand a claim’s evidence and inspect the drift table. | “Documentation claims link back to source evidence, and detected documentation-to-code differences are shown side by side for review.” |
| 1:15–1:55 | In **Model detail**, open the **Redevelopment** tab and show the attempt results and parity certificate levels. | “The rebuild view records attempt outcomes and parity evidence. Review the generated certificate rather than treating an LLM assertion as proof.” |
| 1:55–2:25 | In **Model detail**, open the **Validation** tab; show the rating and checks, then click **Download validation HTML report**. | “Validation combines performance, stability, and fairness checks under a fixed policy; reviewers can inspect the supporting test results and findings.” |
| 2:25–2:45 | Open **Model detail → Monitoring** and point to the recorded trigger month. | “This monitoring path shows a simulated drift trigger and the revalidation handoff; the drift is explicitly simulated.” |
| 2:45–3:00 | Open **Business case**, then **Audit log**. | “The business case is an assumption-based scenario, while measured project metrics are labelled separately. The audit log records workflow decisions for traceability.” |
