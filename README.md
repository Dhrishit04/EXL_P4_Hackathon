# ModelProof

**An agentic model risk factory for a Tier 1 bank.** ModelProof turns a legacy model estate (SAS, R and Python) into an evidence-linked model inventory, documentation that is checked against the code, a Python rebuild of an R model with a five-level parity certificate, and a validation report on performance, stability and fairness, with a human approving at every gate. Built for the EXL x UCD Data & AI Hackathon 2026, Challenge 04, aligned to PRA SS1/23.

> **LLMs propose, deterministic code disposes.** No number, risk tier or RAG status ever comes from the LLM.

## Quickstart

```bash
uv sync --all-extras                                  # install (Python 3.11, base R for the legacy runtime)
cp .env.example .env                                  # add an LLM key; not needed in replay mode
python scripts/fetch_data.py                          # download and split the public datasets
uv run modelproof run --model all --auto-approve      # run the pipeline (recorded LLM calls replay for free)
uv run streamlit run app/Home.py                      # open the validator workbench
```

Other commands: `modelproof discover`, `run --model ID` (stops at each human gate), `approve --thread T --decision approve|reject --comment C`, `status`, `monitor`, `benchmark`, `verify-audit`. `scripts/run_pipeline.sh` does the full live run, a replay run, a comparison of the two and the benchmark.

## Demo mode

`artifacts/` (inventory, documentation, certificates, reports, audit log) and `.cache/llm/` (every recorded LLM response) are committed. With `LLM_MODE=replay` the whole pipeline reruns offline, without a key, and reproduces the same artifacts. The Streamlit app reads `artifacts/` only.

## Responsible AI

* **Human gates.** Discovery, documentation, redevelopment and validation each stop for a named reviewer (LangGraph interrupts, checkpointed in SQLite). `--auto-approve` is a demo flag, recorded as `auto` and never presented as a human approval. A failed parity certificate is never auto-promoted.
* **Hash-chained audit log.** Every decision and agent action is appended to `artifacts/audit/audit_log.jsonl`; `modelproof verify-audit` detects any edit or deletion.
* **The LLM never sees row-level data.** A guard rejects DataFrame dumps and numeric row blocks before any model call; agents receive extracted facts and code excerpts only.
* **Prompt-injection defence.** Source code and documents are wrapped as untrusted data, a deterministic scanner flags injected instructions, and the seeded injection in PR-RB-004 is reported, not obeyed.
* **Sandboxed generated code.** Rebuilt code is statically checked and tested in a restricted subprocess before it is trusted.
* **Deterministic decisions.** Risk tiers, RAG statuses, ratings and parity verdicts come from fixed thresholds in `config/policy.yaml`, set before any run.
* **Evidence-linked claims.** Every documentation and validation claim cites evidence; a deterministic verifier marks unsupported claims instead of hiding them, and doc-versus-code drift is verified line by line.

## Limitations

* The legacy estate is simulated (four models on public datasets); the SAS code is parsed, not executed, because SAS is not available. The R model is the only one with executed golden outputs.
* Monitoring is a simulation of population drift on the holdout, not future credit outcomes.
* LLM-extracted inventory fields can be wrong; the human gate and the verifier exist for that reason, and the benchmark reports their accuracy separately from the deterministic fields.
* Parity is proven for the rebuilt R model only.
